# Course Title: Introduction to Claude Code (1 hour)

## Course Description

Developers spend substantial time navigating unfamiliar project structures, writing boilerplate code, and manually diagnosing test failures. Terminal workflows often require switching contexts between editors, command-line tools, and documentation, slowing down daily development momentum.

This course introduces developers to Claude Code, an agentic command-line tool that assists with software development tasks directly in the terminal. Students learn to launch Claude Code, initialize new projects, prompt for clean code generation, write and execute automated tests, and refactor existing code.

## Learning Objectives

- Use Claude Code in the terminal to build, test, and refactor a coding project
- Launch Claude Code and navigate command-line project workflows
- Prompt Claude Code to scaffold project files and generate feature code
- Direct Claude Code to write tests, diagnose failures, and refactor code

## Who Should Attend

Software developers and engineers who want to use Claude Code to accelerate terminal-based coding, testing, and refactoring workflows.

## Prerequisites

- Basic familiarity with terminal commands and software development
- Claude Code installed and an active account configured

## Hands-On Activities

- Lab: Starting Claude Code and Initializing a Project
- Lab: Generating Code with Claude Code
- Lab: Testing and Refactoring with Claude Code
